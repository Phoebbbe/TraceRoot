# TraceRoot 训练异常诊断平台

TraceRoot 是面向算法工程师的训练异常诊断工作台，用于在训练任务出现 loss 突增、梯度异常、指标长时间不收敛等问题时，基于指标、日志、配置快照和历史实验记录，快速形成可追溯、可验证的诊断结论。

## 项目定位

TraceRoot 不是单纯的监控看板，也不是直接替工程师做最终决策的聊天机器人，而是一个证据驱动的诊断助手。

它将分散在指标、日志、配置和历史实验中的信息组织到同一条诊断链路中，帮助工程师：

- 明确异常发生的时间窗口和影响范围
- 自动匹配可比的历史正常实验
- 对比配置、代码、数据和硬件状态差异
- 输出带证据来源的根因候选及置信度
- 生成可执行的排查步骤
- 在验证后沉淀为结构化诊断笔记和可复用经验

## 核心能力

### 1. 异常触发与上下文采集

系统接收训练指标和日志异常信号，自动截取异常前后的指标窗口、日志片段、配置快照和任务状态，形成一次可追踪的诊断事件。

### 2. 跨实验对比

支持当前异常实验与历史实验进行对比，覆盖：

- 模型和训练配置
- 代码 Commit
- 数据版本与数据分布
- GPU 利用率和硬件健康状态
- loss、梯度范数等关键指标

系统会自动高亮差异最大的特征，并支持与本人或其他工程师保存的历史分析方案进行对比。

### 3. 证据驱动的根因排序

系统围绕异常现象生成多个根因候选，并展示：

- 根因描述
- 置信度
- 支持证据
- 反证或缺失证据
- 建议验证动作
- 引用的指标、日志或历史案例来源

诊断结论不会脱离数据来源单独生成，工程师可以逐条展开证据进行复核。

### 4. Workflow 编排

支持以下方式创建和执行诊断流程：

- 根据异常类型生成 Workflow
- 导入已有 Workflow 模板
- 编辑节点、输入和执行顺序
- 按阶段查看执行状态
- 保存 Workflow 供其他异常类型复用

默认诊断链路为：

```text
异常触发
  ↓
上下文采集
  ↓
可比实验匹配
  ↓
多维差异分析
  ↓
证据门禁与根因排序
  ↓
最小验证动作
  ↓
专家确认
  ↓
诊断笔记沉淀
